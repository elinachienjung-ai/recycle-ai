# 一拍就知道：AI 即時辨識回收物分類網站

目前網址：https://snapsort67.github.io/recycle-ai/ （GitHub repo：snapsort67/recycle-ai）

純 HTML / JavaScript 靜態網站。AI 模型（Teachable Machine 匯出的模型，支援 TFLite 與 TensorFlow.js）直接在瀏覽器裡執行，影像不會上傳。電腦、手機、平板開同一個網址都能用。

## 1. 資料夾內容

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體 |
| `style.css` | 外觀 |
| `app.js` | 主程式（鏡頭、辨識、語音、回報、儀表板） |
| `apps-script.gs` | 貼到 Google Apps Script 的雲端接收程式（見第 4 節） |
| `config.js` | **設定檔**：信心度門檻、類別名稱與圖示、Google 試算表網址 |
| `model/model.tflite`、`model/labels.txt` | Teachable Machine 訓練出的模型 |
| `data/county_rules.json` | 22 縣市 × 7 個回收類別的規則 |
| `data/drink_cup_rules.json` | 飲料杯拆解步驟（手搖飲、咖啡杯；封膜、吸管、杯蓋、杯身、杯套各丟哪裡，附官方來源） |
| `lib/` | TensorFlow.js 與 TFLite 函式庫（已放在網站裡，比賽現場不用連 CDN） |
| `retrain.js` | AI 自學：即時自學記憶（KNN）＋自動重訓（見第 10 節） |
| `lib/mobilenet/` | MobileNet v2（Teachable Machine 用的同一個「看圖」模型），自學功能用來把照片變成特徵 |
| `model/train_features.json`、`.bin` | 原訓練照片（1174 張）事先算好的特徵，自動重訓時跟回報照片一起學 |

## 2. 在自己電腦先試（不用上網部署）

鏡頭只能在 `https://` 或 `http://localhost` 下開啟，直接雙擊 `index.html` **不能用**。

- **方法 A（VS Code）**：安裝擴充功能「Live Server」→ 在 `index.html` 按右鍵 →「Open with Live Server」。
- **方法 B（Python）**：在這個資料夾開終端機，輸入 `python -m http.server 8000`，瀏覽器開 `http://localhost:8000`。

## 3. 免費部署到 GitHub Pages（取得網址）

1. 到 https://github.com 註冊／登入。
2. 右上角「＋」→「New repository」。名稱例如 `recycle-ai`，選 **Public**，按「Create repository」。
3. 在新的 repository 頁面點「uploading an existing file」。
4. 把**這個資料夾裡面的所有東西**（index.html、app.js、config.js、style.css、README.md 和 `model`、`data`、`lib` 三個資料夾）一起拖進網頁。
   - 要拖的是資料夾「裡面」的檔案，不是外層資料夾本身，`index.html` 必須在最上層。
   - 用 Chrome 或 Edge 拖資料夾，子資料夾會自動保留。
5. 下方按「Commit changes」，等上傳完成。
6. 上方「Settings」→ 左邊「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)` → 「Save」。
7. 等 1～3 分鐘，重新整理 Pages 頁面，上方會出現網址：
   `https://你的帳號.github.io/recycle-ai/`
8. 用電腦和手機打開這個網址，允許使用相機，就可以 demo 了。

之後要更新（例如換新模型）：網站支援兩種 Teachable Machine 匯出格式，放進 `model` 資料夾即可：
- **TensorFlow.js（建議）**：`model.json`、`weights.bin`、`metadata.json`（有 metadata.json 時網站自動用這個格式）
- **TensorFlow Lite**：`model.tflite`、`labels.txt`
- 或在 Teachable Machine 選「上傳我的模型」，把分享連結貼到 `config.js` 的 `MODEL_URL`。

## 4. 讓所有使用者的資料存在同一個地方（Google 試算表＋雲端硬碟）

沒設定時，資料只存在每台裝置自己的瀏覽器。設定後，**不管誰、用哪台裝置**，資料都會集中到同一份試算表，儀表板也會顯示所有人的統計：

- 「回報」工作表：每次按 ✅ 對／❌ 不對（含使用者選的物品）
- 「辨識紀錄」工作表：每次按「拍一下」的結果和當時的門檻
- 「樣本」工作表：使用者回報或 AI 沒把握時存下的小照片，等待審核
- 雲端硬碟「一拍就知道_重訓照片」資料夾：在儀表板「審核區」按 ✅ 確認後，照片才會依類別放進這裡

沒網路時會先存在裝置裡，有網路後自動補傳。

**設定步驟（用團隊的 Google 帳號，約 10 分鐘）**

1. 到 https://sheets.new 開一份新的 Google 試算表，命名「一拍就知道資料」。
2. 選單「擴充功能」→「Apps Script」。
3. 把編輯器裡原本的程式全部刪掉，打開這個網站資料夾裡的 **`apps-script.gs`**，全部複製貼上。**把第 6 行的 `REVIEW_CODE` 改成你們自己的審核碼**（只告訴團隊和老師），按 💾 儲存。
4. 右上角「部署」→「新增部署作業」→ 左邊齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按「部署」。第一次會要求授權：選自己的帳號 →「進階」→「前往（專案名稱）（不安全）」→「允許」（因為要寫入試算表和建立雲端硬碟資料夾）。
6. 複製「網頁應用程式網址」（以 `/exec` 結尾），貼到 `config.js` 的 `SHEET_URL: ""` 引號中間。
7. （選填）第一次有人回報照片後，雲端硬碟會出現「一拍就知道_重訓照片」資料夾，把它的網址貼到 `config.js` 的 `PHOTO_FOLDER_URL`，儀表板會顯示連結。
8. 把改好的 `config.js` 重新上傳到 GitHub（或傳給 Claude 幫你改）。

**之後如果修改了 `apps-script.gs`**：要到「部署」→「管理部署作業」→ ✏️ 編輯 → 版本選「新版本」→「部署」，網址不變。

**隱私**：辨識本身都在瀏覽器裡完成，畫面不會上傳。只有兩種情況會存下一張 160×160 的小照片：使用者按「❌ 不對」回報，或 AI 沒把握請使用者重拍時；畫面上都會提醒。照片要經團隊審核才會用來訓練，審核時可以刪掉拍到人的照片。不想收照片：`config.js` 的 `UPLOAD_PHOTOS` 改成 `false`；不想自動存可疑樣本：`SAVE_SUSPECTS` 改成 `false`。

## 5. 用回報資料重新訓練模型

1. 有設定雲端時：到雲端硬碟「一拍就知道_重訓照片」資料夾，下載各類別資料夾。沒設定時：儀表板最下方按「📦 下載重訓照片 ZIP」（只有這台裝置的照片）。
2. 回到 Teachable Machine 專案，把照片上傳到**正確的類別**，再按「Train Model」。
3. 匯出：「Export Model」→「TensorFlow Lite」→「Quantized」→ 下載，把新的 `model.tflite`、`labels.txt` 換掉網站 `model/` 裡的檔案。
   - 如果類別名稱改了，記得同步修改 `config.js` 的 `CLASSES`。

## 6. 常改的設定（config.js）

- `THRESHOLD: 0.5`：信心度低於 50% 會請使用者換角度再拍（過半就顯示答案）。太常認錯就調高（例如 0.6）。
- `CLASSES`：8 個類別（寶特瓶、塑膠類、紙類、紙容器、鐵鋁罐、玻璃容器、電池、背景）的顯示名稱、圖示和別名。網站會用 labels.txt 的名稱自動對應，例如「乾電池」會對到「電池」、「鋁箔包」會對到「紙容器」。辨識到「背景」時會顯示「請把物品放到鏡頭前」；辨識到「飲料杯」（labels 寫手搖杯、咖啡杯也可以）時會顯示飲料杯拆解步驟卡片。

## 7. 使用小技巧（demo 時）

- 按「📸 拍一下」或鍵盤**空白鍵**辨識；結果會大字顯示並語音播報。
- 物品放在畫面**中間**（AI 只看畫面中間的正方形），背景越單純越準。
- 手機有「🔄 換鏡頭」按鈕可切換前後鏡頭。
- 語音沒聲音：確認右上角「🔊 語音」有勾、裝置不是靜音（iPhone 要關掉側邊靜音鍵）。

## 8. 後台儀表板

- 上方可篩選「期間」和「縣市」。
- 數字卡：辨識次數、使用者回報數、回報正確率、沒把握／沒放東西的比例。
- 圖表：各類別正確率、最常被認錯的物品、AI 認錯對照表（混淆矩陣）、最常搞混的組合、每天辨識次數。
- 「自動校準的信心門檻」表格、「審核區」、「已審核的照片」（見第 9 節）。
- 「🧪 顯示示範資料」：給簡報或影片展示儀表板用，是電腦隨機產生的假資料，畫面上方會一直顯示紅色提醒。**不能當成真實測試結果寫進作品說明書。**
- 有設定 Google 試算表時，儀表板顯示所有使用者的資料；沒設定時只顯示這台裝置的。

## 9. 從資料中學習（回報、審核、自動門檻）

1. **選物品回報**：按「❌ 不對」後，使用者點「這是什麼東西」（例如鋁箔包、便當盒、乾電池），網站自動對應到正確類別。物品清單在 `config.js` 的 `ITEMS`。
2. **自動存可疑樣本**：AI 信心度不夠、請使用者重拍時，會自動存下那張小照片（同一段時間連續重拍只存一張）。
3. **審核區**：儀表板裡由團隊或老師確認每張照片的正確類別（或刪除），確認後才會進重訓資料（ZIP 或雲端硬碟資料夾）。雲端模式要輸入審核碼。
4. **自動校準信心門檻**：網站依回報資料計算「AI 猜成某一類時被說不對的比例（認錯率）」，自動調整那一類的門檻：
   - 門檻 = 50% + 0.5 ×（認錯率 − 10%），限制在 50%～90%
   - 那一類的回報少於 10 筆時，用預設 50%
   - 例：認錯率 10% → 50%；30% → 60%；50% → 70%
   - 目前每一類的門檻顯示在儀表板「自動校準的信心門檻」表格。設定在 `config.js` 的 `AUTO_THRESHOLD`。
5. **重新訓練仍是人工**：網站負責收集與整理資料、調整門檻；重新訓練模型要由團隊把審核過的照片放進 Teachable Machine 訓練、匯出，再換上網站。

## 10. AI 自學（即時自學記憶＋自動重訓）

全部在瀏覽器裡完成，不需要伺服器。設定在 `config.js` 的 `MEMORY`、`RETRAIN`，程式在 `retrain.js`。

**原理**：跟 Teachable Machine 一樣分兩段。① MobileNet「看圖」，把照片變成 1280 個數字（特徵）；② 一個小網路看這些數字判斷類別。

1. **即時自學記憶（KNN，只在這台裝置）**
   - 按「拍一下」時網站會連拍 3 張定格畫面。使用者按「❌ 不對」（或「看不太清楚」時按「🧠 告訴 AI 這是什麼」）並選正確物品，就把這 3 張的特徵存進記憶（localStorage，重新整理不會忘）。
   - 之後每次辨識先跟記憶比：最像的 3 張裡，至少 2 張相似度 ≥ 0.85，而且同一類占 ≥ 75%，就直接用記憶的答案（結果會標「🧠 自學記憶」）；否則用原本的模型。
   - 0.85 是用我們 1174 張訓練照片測出來的：不同類別的照片，最像的那張相似度 95% 都低於 0.80，所以 0.85 不太會亂認。
   - 限制：記憶很「專一」，對同一個東西、差不多的位置和光線最有效；換一個不同的瓶子通常不會觸發（會改用原模型）。
2. **自動重訓（所有裝置）**
   - 團隊在儀表板審核區按「✅ 確認」的照片，5 秒後網站會自動用「原訓練照片特徵＋確認照片」重新訓練最後一層（確認照片一張當 3 張用），存在 IndexedDB，下次打開直接用。每台裝置打開網站時都會讀雲端確認照片自己重訓。
   - 確認照片超過約 15 張時，會留 20% 不給它學當小考，儀表板顯示「原模型 vs 重訓模型」各答對幾張。
   - 確認的照片也會放進每台裝置的自學記憶（審核過才共享，避免有人亂教）。
   - **要先更新 Apps Script**：把新版 `apps-script.gs` 貼到 Apps Script（保留你們自己的審核碼那一行），按「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址不會變。沒更新的話儀表板會顯示提醒。
3. **修好訓練照片之後**：在 Teachable Machine 按「儲存專案到檔案」得到 `.tm`，到儀表板按「📂 換訓練照片」選它，網站會重算特徵並下載 `train_features.json`、`train_features.bin`，上傳到 GitHub 的 `model/` 資料夾取代舊檔。原本的 `model.tflite` 也建議重新匯出換掉。
4. 比較用：儀表板「辨識時使用」可切換成「只用原本的模型」。

> 自學只能補強，不能取代好的訓練資料。用我們的訓練照片測試：每類拿編號最後 30% 的照片當「沒看過的照片」，只用前 70% 訓練時答對約 51%（隨機分的話是 82%，代表照片彼此太像、背景太單一）；再加入每類 10 張「新環境」照片重訓，提升到約 68%。寶特瓶、飲料杯各只有 26 張，最需要補拍。
